# In Harmony Naturopathy concept website

A complete static multi-page website concept for a naturopathy and wellness practice.

## Included

- 14 responsive HTML pages
- Home, About, Services, Programmes, Pricing, Journal, and Contact pages
- Seven individual service detail pages
- Subtle scroll reveals and floating hero motion
- Mobile navigation
- Service filtering
- FAQ accordions
- Demo enquiry and newsletter form feedback
- Original SVG illustrations and icons
- Accessibility considerations, including reduced-motion support and a skip link
- General health disclaimers and measured wording

## Open locally

Open `index.html` directly in a browser, or run a local server from this folder:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Before publishing

Replace or verify:

- Practitioner qualifications and professional memberships
- Final service descriptions and suitability criteria
- Prices and programme inclusions
- Opening hours, booking links, and cancellation policy
- Privacy statement and form data handling
- Clinical review of health information
- Demo forms with a real booking or form service

The website uses Google Fonts when online and falls back to common system fonts when offline.
